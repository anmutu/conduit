为什么是 Conduit

每一处差异,都肉眼可感

不追功能数量,只把关键体验做到底

切换即生效,零重启

本地代理接管全部 CLI 流量,切换供应商只改一个指针。Codex / Gemini 与 Claude 一致,告别重启终端。

Key 永不落盘明文

API Key 存系统钥匙串(Keychain / DPAPI / Secret Service),配置库整库 SQLCipher 加密,文件泄露也读不出凭证。

转发即计量

代理转发的同时原生统计 token 用量,卡片上一眼看清每个供应商的消耗,零额外请求。

代理优先架构

代理是默认体验而非高级选项。关闭窗口驻留托盘常驻服务,你的 CLI 永不断流。

自动发现现有第三方配置一键导入;托盘快速切换;中英双语;深浅主题;开机自启;安装包仅 ~9MB。

随时全身而退

接管前原配置自动加密备份,一键还原;所有数据只在本机,不上传任何服务器。

FAQ

常见问题

接管会破坏我的现有配置吗?
不会。接管前原配置完整备份进加密库,「还原」随时恢复;Claude 的 settings.json 只动 ANTHROPIC_BASE_URL 一项,Codex 的 config.toml 保留全部注释。
Conduit 没开,CLI 还能用吗?
接管模式下 CLI 指向本地代理,Conduit 未运行则请求失败——建议开启「开机自启」或让它驻留托盘;介意的话随时「还原」回直连。
支持哪些供应商?
任何 Anthropic / OpenAI / Gemini 兼容的供应商:官方、GLM、Kimi、DeepSeek、各类中转站,或自建网关。
能和 cc-switch 同时用吗?
不建议——两者改写同一批 CLI 配置文件会互相覆盖。从 cc-switch 迁移:用「从现有 CLI 配置导入」一键带入。
