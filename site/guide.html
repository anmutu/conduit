1
准备

下载与安装

Keyway 是一个免费的 macOS 桌面应用。从 GitHub Releases 下载 .dmg,拖入「应用程序」即可,无需其他依赖。

  • 首次打开若提示「无法验证开发者」,请在 系统设置 → 隐私与安全性 中点击「仍要打开」。
  • 启动后 Keyway 会常驻菜单栏(托盘),关闭窗口不影响代理运行。
  • 本地代理默认监听 127.0.0.1:9527,只接受本机请求。
它怎么工作?Keyway 接管各 AI CLI 的 API 地址后,所有请求先到本地代理,再转发到你选定的供应商。切换只改本地状态、不重写 CLI 配置 —— 这就是"免重启"的原因。
2
配置

添加供应商

打开主界面,按 CLI 分组(Claude Code、Codex、Gemini CLI 等)添加你要用的模型供应商:

  • 预设直选:内置常见供应商与中转站,填入 API Key 即可用。
  • 从现有配置导入:已在 CLI 里配过?一键导入,不用重新填。
  • 自定义:填名称、Base URL、API Key,任意中转/自建网关都支持。
密钥安全:API Key 存入系统钥匙串 + 整库加密的本地数据库,不会明文写进任何 CLI 配置文件,导出备份也不含密钥。

添加完成后,可点击供应商卡片上的 测速按钮 检查连通性与延迟,再决定用谁。

3
接管

一键接管 CLI

在分组页点击 「接管」,Keyway 会把该 CLI 的配置指向本地代理:

  • 接管前自动备份原配置,随时可一键还原,不留残留。
  • 接管后 CLI 照常使用 —— 你不需要改变任何使用习惯。
  • 也可以不接管,手动给 CLI 设置环境变量指向 127.0.0.1:9527(应用内有可复制的变量)。
keyway — takeover
» 点击 接管 Claude Code
✓ 已备份 ~/.claude/settings.json → keyway.bak
✓ 已接管,代理 127.0.0.1:9527 运行中
4
日常

切换:秒生效,不重启

这是 Keyway 与"改配置文件"类工具最大的不同 —— 切换只改本地状态,下一个请求立即走新供应商:

  • 主界面点供应商卡片上的 「切换」,或直接在菜单栏托盘里选,两秒钟完成。
  • 全局快捷键 ⌘⇧K(Windows/Linux 为 Ctrl+Shift+K)随时唤起快速切换面板:↑↓ 选择、Enter 切换、Esc 关闭,手不离键盘。
  • 正在运行的 claude / codex 会话无需重启,发下一条消息就已切换。
  • 同一供应商可按协议复用到多个 CLI(如一个中转 Key 同时供 Claude Code 和 Codex)。
  • 自动协议转换:只配置了 OpenAI 兼容端点的供应商,也能直接给 Claude Code 等 Anthropic 协议 CLI 使用 —— Keyway 会在本地完成请求/响应/流式与工具调用的双向转换,无需上游支持 Anthropic 协议。
claude — running session
» 托盘切换: GLM Coding Plan → Kimi
✓ 已切换 → Kimi
» codex "continue"
POST /v1/chat/completions → Kimi 200 · 1.2s (会话未重启)
5
进阶

路由 · 故障转移 · 日志 · 档案

模型路由规则 —— 在「设置 → 模型路由」里,让特定模型永远走特定供应商:

  • 例:规则 claude → 中转站 A;规则 deepseek → 官方。CLI 里指定模型名,Keyway 自动分发。
  • 匹配方式可选「包含」或「前缀」:前缀更精准,避免关键词误命中。
  • 每条规则可临时停用(开关),保留配置不删除;规则从上到下匹配,首条命中生效,可用 ↑↓ 调整顺序。
  • 命中规则的请求会在「日志」页打上蓝色标记,分流效果一目了然。
  • 长上下文分流:超大数据量的请求(阈值可调,默认 6 万 token 估算)自动改走指定供应商 —— 大上下文走便宜渠道,日常对话不受影响。命中时响应头带 x-keyway-route。

自动故障转移 —— 上游 5xx 或超时时,自动重试备用供应商,长任务不中断。把多个供应商加入候选链即可。

用量与日志 —— 侧栏「用量」按 CLI / 供应商汇总 token 与成功率;「日志」可查最近 100 条请求(模型、上下行 token、状态码),排障一目了然。

配置档案与备份 —— 「设置」里可将当前供应商组合保存为档案(工作 / 个人 / 测试一键整组切换),也可导出 JSON 备份(不含密钥),换机无忧。

?
排障

遇到问题?

  • 请求 401 / 403:响应头带 x-keyway-hint,按提示检查 Key 是否有效、额度是否充足。
  • 切换没生效:确认该 CLI 已被接管(分组页有接管状态),或环境变量指向 127.0.0.1:9527。
  • 想恢复原样:分组页「还原」即可,原配置在接管时已备份。
  • 数据在哪:全部在本机加密数据库,不上传任何服务器;卸载即彻底清除。
