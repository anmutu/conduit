# Codex 使用指南

> 在 Conduit 中配置并管理 OpenAI Codex CLI 的供应商:添加 Key、一键接管、免重启切换。

## 它是怎么工作的

```
codex CLI ──► Conduit 本地代理(127.0.0.1:9527)──► 当前供应商(转发 + 注入 Key)
```

- **接管**会把 `~/.codex/config.toml` 中的 `base_url` 改写为 `http://127.0.0.1:9527/v1`(改写前自动备份,可随时还原)
- 你的 **API Key 存在系统钥匙串**(Keychain),不落盘、不入库;转发请求时才由代理注入
- **切换供应商只改一个指针**——正在运行的 codex 会话不用重启,下一个请求立即生效

## 前置条件

| 需要 | 说明 |
|---|---|
| Codex CLI | 已安装并可运行 `codex` 命令 |
| 一个 OpenAI 兼容供应商 | 供应商提供的 `base_url` + `API Key` |
| Conduit | 已启动,顶栏显示绿色「代理运行中」 |

## 配置四步

### ① 切换到 Codex 分组

窗口顶部应用切换胶囊中点击 **Codex**。

### ② 添加供应商

点击右上角 **+** 按钮(或按 `⌘N` / `Ctrl+N`):

| 字段 | 填写说明 | 示例 |
|---|---|---|
| 名称 | 自定义,方便辨认 | `CoderPlan` |
| 接口地址 | 供应商给的地址。**带不带 `/v1` 都可以**,Conduit 会自动处理 | `https://api.example.com/v1` |
| API Key | 供应商提供的 Key。存入系统钥匙串,永不明文落盘 | `sk-...` |

点击「添加」。

> 💡 首次添加时 macOS 可能弹出钥匙串授权,请选择「**始终允许**」。

### ③ 设为当前供应商

鼠标悬停到供应商卡片上,点击蓝色「**切换**」按钮。卡片出现蓝色边框和「当前」徽章即成功。

### ④ 接管 Codex

1. 点击顶栏绿色的「**代理运行中**」标签,打开「代理接管」面板
2. 在 **Codex** 一行点击「**接管**」
3. 看到状态变为 ✅「已接管,流量走代理」即完成

接管后 **新开的** codex 会话即经 Conduit 转发(Codex 启动时读取一次配置,这是唯一需要重开会话的一次;之后的供应商切换永远免重启)。

## 日常使用

### 切换供应商(免重启)

- **主界面**:卡片 hover → 「切换」
- **托盘**:菜单栏 Conduit 图标 → 右键 → Codex → 选择供应商(当前项有 `●` 标注)

切换后无需任何重启,下一个请求立即走新供应商。

### 查看用量

每次请求经代理转发时自动统计,无需任何配置。卡片右侧显示:

```
128 次请求
↓ 412.0k · ↑ 1.3M
```

### 修改供应商

卡片 hover → 铅笔图标。名称、地址可直接改;API Key 留空表示保持不变,填新值则更新到钥匙串。

### 复制 / 删除

- 复制:卡片 hover → 复制图标(快速建一个改改地址的副本)
- 删除:卡片 hover → 垃圾桶图标(需二次确认,钥匙串中的 Key 一并清除)

## 取消接管(还原官方配置)

1. 点击顶栏「代理运行中」标签
2. Codex 行点击「**还原**」

`~/.codex/config.toml` 会被恢复为接管前的原始内容(从加密备份中还原),codex 回到直连模式。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 接管面板显示「未检测到配置」 | 你还没运行过 Codex。可先跑一次 `codex` 生成配置,或直接点「接管」——Conduit 会创建最小配置 |
| 状态显示 ⚠️「配置被外部修改」 | Codex 或其他工具改写了 `config.toml`。重新点一次「接管」即可 |
| codex 报 `Connection refused` / 请求失败 | ① 确认 Conduit 正在运行(托盘有图标);② 确认顶栏是绿色「代理运行中」;③ 若红色,重启 Conduit |
| codex 报 502「未设置 codex 的当前供应商」 | 当前分组里没有任何供应商被设为「当前」——去主界面给某张卡片点「切换」 |
| codex 报 401 / 鉴权失败 | 供应商的 API Key 不对:编辑供应商,重新填 Key(检查是否复制完整、有无多余空格) |
| 模型不存在 / 404 model not found | 供应商不 support 你 `config.toml` 里 `model = "..."` 配置的模型名,改用该供应商支持的模型 |
| 地址填了带 `/v1`,担心拼错 | 不用担心:Conduit 自动去重 `/v1/v1`,带不带 `/v1` 均可 |
| 钥匙串反复弹窗 | 打开「钥匙串访问」→ 搜索 `conduit` → 该条目访问控制中勾选「始终允许」 |

## 数据与安全

| 数据 | 位置 | 保护 |
|---|---|---|
| API Key | macOS 钥匙串 | 系统级加密,Conduit 外的进程无法读取 |
| 供应商配置 / 接管备份 / 用量记录 | `~/Library/Application Support/com.conduit.desktop/conduit.db` | SQLCipher 整库加密(主密钥在钥匙串) |
| 接管时的原配置备份 | 同上(加密 DB 内) | 还原时解密写回 |

## 快捷键速查

| 快捷键 | 功能 |
|---|---|
| `⌘N` / `Ctrl+N` | 添加供应商 |
| `⌘1` ~ `⌘5` | 切换应用分组(Claude / Codex / Gemini / OpenCode / OpenClaw) |
| `Esc` | 关闭弹窗 / 从设置页返回 |
